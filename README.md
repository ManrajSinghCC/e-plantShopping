# e-plantShopping

**Paradise Nursery** — a React shopping cart application for browsing and buying houseplants.

Built as the final project for the IBM *Developing Front-End Apps with React* course
(IBM Skills Network / Coursera).

---

## About the project

Paradise Nursery is a small online plant shop. Visitors land on a welcome page,
browse a catalogue of 30 houseplants across five categories, add what they want
to a cart, adjust quantities, and see the total update as they go.

The cart is managed with **Redux Toolkit**, so every part of the interface reads
from a single source of truth and stays in sync automatically.
